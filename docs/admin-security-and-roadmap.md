# الإدارة والأمان والمتطلبات التقنية - TARAB

## لوحة الإدارة والمشرفون والأمان
- لوحة الإدارة الرئيسية مستقلة عن تطبيق اللاعبين وللمدير الرئيسي الصلاحية الأعلى.
- نظام إدارة المشرفين يحدد عدد المشرفين، ينشئ حساباً مستقلاً لكل مشرف، ويحدد الصلاحيات ببروتين لكل حساب مع مراقبة النشاط المباشر وسجل رقابي لكل عملية.
- مصادقة الأمان والغش للمديرين، طلب كلمة مرور قبل العمليات الخاصة، كشف الفواتير الوهمية والمتعددة، ومراقبة السلوك المشبوه وتجميد العمليات المشبوهة.

## المتطلبات التقنية ومراحل التنفيذ
- واجهة التطبيق: Flutter، الخادم الخلفي: Node.js، قاعدة البيانات: PostgreSQL، الاتصال المباشر: WebSocket، الإشعارات: Firebase، تخزين الصور والملفات: Cloud Storage، ولوحة الإدارة: Web Dashboard.
- خطة التنفيذ مقسمة إلى ست مراحل (الواجهات، الأصدقاء والتصنيف والبطولات، الاقتصاد الداخلي والكوينز والمهام وVIP، لوحة الإدارة والأمان والتقارير، التأسيس المكتمل باللاعبين الفعليين، ثم اختبار الكمبيوتر والغش والصلاحيات والأرصدة قبل الإطلاق على Android وiOS).

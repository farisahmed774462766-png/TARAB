2. نظام اللعب والطاولات

تستمر الجلسة دون حد أقصى حتى يقرر أحد اللاعبين المغادرة أو يرفض الاستمرار.
مغادرة لاعب أو رفضه الاستمرار ينهي الجلسة وفق قواعدها.

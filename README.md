# طراب (TARAB) — لعبة ورق لحظية (5 مقاعد)

مشروع متكامل لبناء وتوثيق لعبة الورق **طراب (TARAB)**، ويضم:
- **تطبيق الهاتف (`mobile-app`):** مبني بـ Flutter مع دعم العربية والإنجليزية (`RTL` / `LTR`)، عرض المحفظة والديون، شبكة الطاولة ذات الـ 5 مقاعد، واجهة جولة الأوراق والدور، وخدمة الاتصال اللحظي `TarabSocketService`.
- **الخادم اللحظي (`backend-server`):** مبني بـ Node.js و`ws` و`pg` لإدارة الطاولات، المحافظ والديون، جولات الأوراق، الأصدقاء والدعوات، نظام VIP ونقاط الولاء، والمواسم والبطولات.
- **قاعدة البيانات (`database/schema.sql`):** مخطط جداول PostgreSQL لتخزين اللاعبين، المحافظ، المعاملات، الطاولات، والمقاعد.
- **لوحة تحكم المسؤول (`admin-dashboard/index.html`):** واجهة إدارية لمتابعة الطاولات، اللاعبين، حسابات الديون، وصرف المكافآت أو بدء فصل جديد.

---

## قواعد النظام الأساسية

1. **الطاولة والمقاعد:** تتكون كل طاولة من **5 مقاعد**، ورسوم الدخول تقع ضمن النطاق المسموح (**1,000 إلى 100,000** كوينز).
2. **المحفظة والديون:**
   - وجود دين غير مسدد يمنع دخول الطاولات حتى تتم تسويته.
   - أي مكافأة أو إعلان اختياري أو عائد يُضاف للحساب يُوجَّه **أولاً** لسداد الدين تلقائياً، ثم يُضاف الفائض إلى رصيد الكوينز.
3. **الجانب الاجتماعي وVIP والمواسم:**
   - قائمة أصدقاء بحد أقصى 30 صديقاً، دعوات الجداول الخاصة، ونظام إحالة.
   - فئات VIP (الفضية، الذهبية، الماسية) ونقاط الولاء واستبدالها بالكوينز ومهلة السماح (3 أيام).
   - فصول تصنيف (يومية، أسبوعية، شهرية) مع تصفير النقاط لبداية فصل جديد مع الإبقاء على السجل التاريخي.

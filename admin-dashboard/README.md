# لوحة الإدارة - TARAB (Web Dashboard)

## نظرة عامة
لوحة إدارة رئيسية مستقلة عن تطبيق اللاعبين، يتولى فيها المدير الرئيسي أعلى الصلاحيات لإدارة النظام والمراقبة والتقارير.

## الأقسام والمهام الأساسية
- **الإدارة العامة والحسابات:** لوحة الإحصائيات العامة، إدارة حسابات اللاعبين، الجداول والمباريات، البطولات والتصنيفات، الكوينز والديون، الأعمال والمكافآت، VIP والاشتراكات، المتجر والهدايا، الإعلانات، الأصدقاء والحالات، البلاغات والاعتراضات، الدعوى القضائية، والإعدادات العامة.
- **المشرفون والصلاحيات:** تحديد عدد المشرفين وإنشاء حساب مستقل لكل مشرف بصلاحيات بروتينية، ومراقبة النشاط المباشر وحفظ السجل الرقابي والترتيب الشهري.
- **الأمان ومكافحة الغش:** مصادقة الأمان للمديرين، طلب كلمة مرور قبل العمليات الخاصة، كشف الفواتير الوهمية والمتعددة، ومراقبة وتجميد السلوك والعمليات المشبوهة.
- **التقارير المالية:** إعداد التقارير المالية الدورية وتصدير البيانات بصيغتي Excel وPDF.

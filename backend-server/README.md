# خادم اللعبة - TARAB (Node.js & WebSocket)

## نظرة عامة
الخدمة الخلفية المسؤولة عن إدارة منطق لعبة الورق **TARAB**، الجداول والطاولات (5 مقاعد)، المطابقة بين اللاعبين، والاتصال اللحظي عبر **WebSocket**.

## المهام الأساسية للخادم
- **إدارة الطاولات والمطابقة:** إنشاء الجداول العامة والخاصة، توزيع اللاعبين حسب مستوى التصنيف، وضمان عدم بدء اللعبة القانونية قبل اكتمال المقاعد الخمسة.
- **الاتصال اللحظي (WebSocket):** مزامنة حركة الأوراق والأدوار والرسائل والتفاعلات الفورية بين اللاعبين في الوقت الفعلي.
- **حفظ الحالة والاتصال:** دعم التوافر السلمي لحظياً، وحفظ حالة اللعبة عند انقطاع الشبكة مع إمكانية العودة واستكمال اللعب.
- **التكامل مع البيانات والخدمات:** الربط مع قاعدة البيانات لحفظ الحسابات والأرصدة والسجلات والبطولات، والتكامل مع خدمات الإشعارات والتخزين.

# تطبيق الهاتف - TARAB (Flutter)

## نظرة عامة
تطبيق لعبة الورق الجماعية **TARAB** لنظامي **Android** و**iOS**، مبني باستخدام إطار العمل **Flutter** لتوفير أداء سلس وتجربة بصرية متجاوبة.

## المميزات الأساسية في التطبيق
- **اللغات والواجهة:** دعم اللغة العربية بشكل أساسي مع اتجاه من اليمين إلى اليسار (RTL)، بالإضافة إلى دعم اللغة الإنجليزية، بتصميم عصري وتأثيرات ورسوم متحركة سلسة.
- **شاشات الطاولة (5 مقاعد):** واجهة لعب مصممة لاستيعاب 5 مقاعد لكل طاولة، مع عرض واضح للأوراق، الأدوار، وحالة اللاعبين لحظياً، وعدم بدء اللعبة القانونية قبل اكتمال المقاعد الخمسة.
- **الشخصيات المخصصة:** دعم الشخصيات التفاعلية المخصصة التي تطرح أفكارها وتعليقاتها للاعبين الحقيقيين أثناء اللعب، وإكمال المقاعد بشخصيات آلية تحاكي اللاعبين الحقيقيين عند نقص العدد.
- **التفاعل الاجتماعي والاقتصاد:** شاشات الملف الشخصي، الأصدقاء، المحادثة الكتابية خارج المباريات، التفاعلات والملصقات أثناء اللعب، محفظة الكوينز والديون، والمكافآت اليومية ونظام VIP.

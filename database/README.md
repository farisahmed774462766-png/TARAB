# قاعدة البيانات - TARAB (PostgreSQL)

## نظرة عامة
قاعدة البيانات العلائقية المسؤولة عن حفظ البيانات الأساسية والعمليات المالية وسجلات اللعب والتنافس في لعبة **TARAB**.

## المجالات الرئيسية للبيانات
- **حسابات اللاعبين والملفات الشخصية:** بيانات الحساب، الصورة الشخصية والإطار، الاسم ورقم ID، مستوى التصنيف، قائمة الأصدقاء، وقائمة المفضلة.
- **الأرصدة والديون والفواتير:** أرصدة الكوينز، سجل الديون وسدادها، سجل الفواتير والعمليات، ومكافآت الإعلانات والمهام.
- **المباريات والبطولات والتصنيف:** سجل المباريات، نقاط التصنيف والمواسم الشهرية، والبطولات (يومية، أسبوعية، شهرية).
- **الاشتراكات والإدارة والأمان:** عضوية VIP وفئاتها ونقاط VIP، سجل الرقابة والمشرفين، البلاغات، والتقارير المالية.
